# Pool Day

> Your Jira backlog, but make it fun.

Pull your issues into a living canvas. See what's blocked, what's next, drag things around — it's your backlog, finally feeling like yours.

---

## Features

- **Magnetic drag & drop** — move cards around a freeform canvas
- **AI-condensed titles** — long Jira summaries trimmed to something readable
- **Next indicator** — always know what to pick up next

## Card states

| State       | Meaning                        |
| ----------- | ------------------------------ |
| **Blocked** | Issue is stuck, needs action   |
| **In Progress** | Actively being worked on   |
| **Backlog** | Raw, not yet started           |

---

## Stack

- **React** + Hono API
- **NeonDB** (Postgres)
- Jira integration for pulling issues
